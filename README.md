# 复古猫桌面宠物（Windows / macOS）

一个在本地运行的复古猫桌面宠物，支持透明悬浮、点击互动、自主活动、睡觉以及键盘输入联动。

> [!IMPORTANT]
> **下载和运行前，请先完整阅读本页。解压后还必须阅读安装包内对应的 `INSTALL_WINDOWS.md` 或 `INSTALL_MACOS.md`。**
>
> 大多数启动问题都来自以下情况：下载了错误的系统版本、没有完整解压、单独移动了启动文件，或没有授予 macOS 输入监控权限。

## 下载

[前往 Releases 下载最新版本](https://github.com/YicongJiang/VintageCatDesktopPet/releases)

请根据自己的操作系统选择文件，两个版本不能混用：

| 操作系统 | 下载文件 | 启动文件 | 是否需要自行安装 Python |
|---|---|---|---|
| Windows 10/11 64位 | `VintageCatPet_Windows_Portable.zip` | `VintageCatPet.exe` | 不需要，便携版已包含运行环境 |
| macOS | `VintageCat_DesktopPet_macOS.zip` | `start_vintage_cat.command` | 需要已有 Python 3.10+ 或 Conda；启动器会自动建立独立环境 |

> [!WARNING]
> 不要在 ZIP 压缩包预览窗口里直接运行程序。必须先将整个 ZIP 完整解压，并保持文件夹内部结构不变。

## Windows 使用方法

1. 下载 `VintageCatPet_Windows_Portable.zip`。
2. 右键压缩包，选择“全部解压”。
3. 打开解压得到的 `VintageCatPet` 文件夹。
4. 双击 `VintageCatPet.exe`。

Windows 版已经包含 Python、Tk 和 Pillow，普通用户不需要安装 Python、Anaconda 或其他依赖。

请勿删除或改名 `_internal` 文件夹，也不要把 `VintageCatPet.exe` 单独移动到其他位置。如果希望从桌面启动，请为 EXE 创建快捷方式。

如果 Windows SmartScreen 显示“Windows 已保护你的电脑”，这是因为本项目没有商业代码签名。请先确认文件来自本仓库的 Releases，再选择“更多信息”与“仍要运行”。不要因此永久关闭 Windows Defender 或 SmartScreen。

完整说明和故障排查见解压目录中的 `INSTALL_WINDOWS.md`。

## macOS 使用方法

1. 下载 `VintageCat_DesktopPet_macOS.zip` 并完整解压。
2. 建议将整个文件夹移动到桌面或用户主目录，不要只移动启动文件。
3. 按住 Control 键单击 `start_vintage_cat.command`。
4. 选择“打开”，并确认运行。
5. 第一次运行可能需要联网创建独立环境并安装 PyQt5，请等待终端提示完成。
6. 按照系统提示授予输入监控权限，然后完全退出终端和桌宠并重新启动。

macOS 版支持 Python 3.10 及以上版本，包括 Python 3.12。启动器会优先创建项目专用虚拟环境；如果电脑已有 Conda，也可以自动建立包含 Python 3.12 和 PyQt5 的独立环境。现代 macOS 不保证预装可供本项目使用的 Python，因此第一次运行前请确认电脑至少已有 Python 3.10+ 或 Anaconda、Miniconda、Miniforge。

键盘联动需要前往：

```text
系统设置 → 隐私与安全性 → 输入监控
```

允许实际启动桌宠的终端或 Python。密码输入框、系统登录界面及部分安全软件可能启用 Secure Input，此时 macOS 会暂时屏蔽全局键盘监听，程序无法绕过该系统安全机制。

完整说明和故障排查见解压目录中的 `INSTALL_MACOS.md`。

## 主要功能

- 透明、置顶的本地桌面宠物。
- 待机、张望、散步、摸头反馈、挥手、鞠躬和睡觉动画。
- 单击、双击、拖动、右键菜单、位置记忆和大小调整。
- 入睡时只播放一次“打哈欠 → 躺下”，随后保持静态，直到再次互动。
- 检测实体键盘输入后自动进入坐姿打字场景。
- 字母、数字、常用符号和功能键会映射到键帽高亮与左右爪动作。
- 快速连续输入时，每次按键都会进入独立动作队列。
- 连续 5 分钟没有键盘输入后自动恢复普通桌宠模式。
- 自主活动频率较低，避免持续打扰正常工作。

## 基本操作

| 操作 | 效果 |
|---|---|
| 左键单击 | 摸摸复古猫；睡着时将其唤醒 |
| 左键双击 | 触发短暂的打招呼动作 |
| 按住左键拖动 | 移动桌宠位置 |
| 右键单击 | 打开功能菜单 |
| 开始使用键盘 | 自动进入键盘联动模式 |
| 5分钟没有键盘输入 | 恢复待机与自主活动模式 |

右键菜单可以控制睡觉/醒来、自动散步、大小、总在最前、回到右下角、开机或登录启动，以及退出程序。

## 隐私说明

桌宠在本机运行，不会保存你输入的文字，不创建按键内容日志，也不会把输入内容上传到网络。键盘功能只在内存中接收按键事件或判断按键状态，用于选择爪子动作和键帽高亮。

Windows 便携版日常运行不需要联网。macOS 版第一次建立 Python/Qt 环境时可能访问 Python 或 Conda 软件源，环境安装完成后桌宠本身可以离线运行。

## 遇到问题时

请先重新阅读安装包中的系统说明，并确认：

1. ZIP 已经完整解压。
2. 没有拆散、删除或改名程序文件。
3. 后台没有同时运行新旧两个版本。
4. 下载的版本与当前操作系统一致。
5. macOS 已向正确的终端或 Python 授予输入监控权限。

如果仍然无法解决，提交问题时请同时提供：

- 操作系统版本；
- Windows 版本号或 Mac 芯片类型；
- 问题截图；
- 执行了哪些操作；
- Windows 的 `%APPDATA%\VintageCatPet\startup_error.log`，或 macOS 程序目录中的 `startup_error.log` 和 `startup_status.json`。

请不要只描述“打不开”或“没有反应”，日志和截图能够显著缩短排查时间。
